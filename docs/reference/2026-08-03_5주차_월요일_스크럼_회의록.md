## 공통

- TA님 피드백과 이전에 합의한 프로젝트 방향을 다시 확인하며 구현한다.
- 사진을 사용하는 기능은 단순 이미지 URL을 DB에 저장하지 않고, `storage_type`과 `object_key`를 기반으로 최종 URL을 조립하는 방식을 사용한다.
  - 현재 지원 구현체는 로컬 저장소와 MinIO 오브젝트 스토리지다.
  - 이후 AWS S3 등 저장소가 늘어나도 `StorageUrlResolver` 인터페이스 구현체를 추가하는 방식으로 확장한다.
- URL 조립 공통 로직은 조직의 `yes-ai-do-commons` 저장소에 라이브러리 형태로 제공된다.
- GitHub Packages용 개인 토큰을 각 개발 PC에 설정하는 대신, 공개 공통 라이브러리는 JitPack을 사용해 Maven 의존성으로 가져온다.
  - Maven `repositories`에 `https://jitpack.io`를 추가한다.
  - Maven `dependencies`에 `com.github.nhnacademy-aiot3-yes-ai-do:yesaido-common:v1.0.0`을 추가한다.
  - 의존성을 추가하기 전 해당 태그(`v1.0.0`)와 공개 저장소가 실제로 준비되어 있는지 확인한다.
